mcctl puts every Minecraft Java server you host behind a single port. A server starts when the first player connects and stops after it goes idle, so an empty host runs only the router — about 40 MB of RAM. Manage it all from the CLI or the web console. mcctl은 직접 운영하는 마인크래프트 자바 서버를 포트 하나 뒤에 모읍니다. 첫 플레이어가 접속하면 서버가 켜지고, 아무도 없으면 다시 꺼집니다. 그래서 빈 호스트에는 라우터만 남습니다(RAM 약 40MB). 관리는 CLI나 웹 콘솔에서 합니다.mcctl は、あなたが運用するすべての Minecraft Java サーバーをひとつのポートの後ろにまとめます。最初のプレイヤーが接続するとサーバーが起動し、誰もいなくなれば停止します。空いているホストで動くのはルーターだけ — RAM 約 40MB です。管理は CLI でも Web コンソールでも行えます。

01 / Features기능機能

Built for people who host for friends.친구들 서버를 직접 굴리는 사람을 위해.友だちのためにサーバーを立てる人のために。

01

One port, every server포트 하나로 모든 서버ひとつのポートで全サーバー

mc-router reads the hostname a player connects with and forwards them to the matching container. Use nip.io names with no client setup, .local names over mDNS, or a playit.gg tunnel for friends outside your network.mc-router가 접속 주소의 호스트명을 보고 해당 컨테이너로 연결합니다. 클라이언트 설정이 필요 없는 nip.io 주소, mDNS(.local) 주소, 외부 친구용 playit.gg 터널을 지원합니다.mc-router はプレイヤーが接続に使ったホスト名を読み取り、対応するコンテナへ転送します。クライアント設定不要の nip.io アドレス、mDNS の .local アドレス、ネットワーク外の友だち向けの playit.gg トンネルが使えます。

survival.192.168.1.50.nip.io→mc-survival
creative.local→mc-creative
xx-xx.craft.playit.gg→mc-modded
02

Asleep until someone joins누군가 들어올 때까지 잠들기誰かが来るまで眠らせる

Servers start on the first connection and stop after an idle timeout. When nobody is playing, only the router and its helpers stay up.첫 접속에 서버가 켜지고, 일정 시간 아무도 없으면 꺼집니다. 아무도 플레이하지 않을 때는 라우터와 보조 서비스만 남습니다.最初の接続でサーバーが起動し、一定時間誰もいなければ停止します。誰も遊んでいないときに動いているのは、ルーターと補助サービスだけです。

survivalrunning
moddedstarting
creativeexited
03

Mods and modpacks from the CLI모드와 모드팩을 CLI로Mod とモッドパックを CLI で

Search and add mods from Modrinth, CurseForge, and Spiget. Create a server straight from a Modrinth modpack — the loader is detected and client-only mods are left out.Modrinth, CurseForge, Spiget에서 모드를 찾아 추가합니다. Modrinth 모드팩으로 바로 서버를 만들면 로더를 자동으로 감지하고 클라이언트 전용 모드는 뺍니다.Modrinth、CurseForge、Spiget から Mod を検索して追加できます。Modrinth のモッドパックから直接サーバーを作ると、ローダーを自動検出し、クライアント専用 Mod は除外します。

$ mcctl create pack -t MODRINTH --modpack cobblemon
04

Worlds that move between servers서버를 옮겨 다니는 월드サーバー間を移動できるワールド

Worlds live in one shared directory. Assign a world to a server and it stays locked until released. Import worlds from ZIP, then browse dimensions, structures, players, and a BlueMap web map.월드는 공용 디렉터리 한곳에 보관됩니다. 서버에 할당한 월드는 해제할 때까지 잠깁니다. ZIP으로 월드를 가져오고 차원·구조물·플레이어 정보와 BlueMap 웹 지도를 볼 수 있습니다.ワールドは共有ディレクトリにまとめて保存されます。サーバーに割り当てたワールドは、解除するまでロックされます。ZIP からワールドを取り込み、ディメンション・構造物・プレイヤー情報や BlueMap の Web マップを確認できます。

$ mcctl world assign hardcore-01 survival
05

Backups to your GitHub내 GitHub로 백업GitHub へバックアップ

Push world data to a private GitHub repository on demand or on a cron schedule with retention, and restore from any backup commit.월드 데이터를 비공개 GitHub 저장소에 직접 또는 cron 일정으로 푸시하고 보관 정책을 적용합니다. 원하는 백업 커밋으로 복원할 수 있습니다.ワールドデータを非公開の GitHub リポジトリへ手動または cron スケジュールでプッシュし、保持ポリシーを適用できます。任意のバックアップコミットから復元できます。

$ mcctl backup schedule add --cron daily

03 / Architecture아키텍처アーキテクチャ

One port in. One container per server.들어오는 포트는 하나, 서버마다 컨테이너 하나.入口のポートはひとつ、サーバーごとにコンテナひとつ。

Built on itzg/minecraft-server and itzg/mc-router. No firewall rule per server, no port list to remember.itzg/minecraft-server와 itzg/mc-router 기반. 서버마다 방화벽 규칙을 열거나 포트 번호를 외울 필요가 없습니다.itzg/minecraft-server と itzg/mc-router がベースです。サーバーごとにファイアウォールを開けたり、ポート番号を覚えたりする必要はありません。

Each colour is one hostname. mc-router reads it from the Minecraft handshake and forwards the player to that container — starting it first if it is asleep. mcctl and Minecraft Server Manager drive the containers through Docker.색 하나가 호스트명 하나입니다. mc-router가 접속 패킷에서 호스트명을 읽어 해당 컨테이너로 보내고, 잠든 서버는 먼저 깨웁니다. mcctl과 Minecraft Server Manager는 Docker를 통해 컨테이너를 관리합니다.色ひとつがホスト名ひとつです。mc-router は Minecraft のハンドシェイクからホスト名を読み取り、そのコンテナへプレイヤーを転送します。眠っていれば先に起動します。mcctl と Minecraft Server Manager は Docker を通じてコンテナを管理します。

04 / External access외부 접속外部アクセス

Play with friends outside your home.집 밖에 있는 친구와도 함께.家の外にいる友だちとも一緒に。

By default your servers are reachable only on your home network. Turn on playit.gg and friends anywhere can join — no port forwarding, no router settings, no static IP. A free playit.gg account is enough.기본적으로 서버는 우리 집 네트워크 안에서만 접속됩니다. playit.gg를 켜면 어디에 있는 친구든 들어올 수 있습니다. 포트 포워딩도, 공유기 설정도, 고정 IP도 필요 없고 무료 playit.gg 계정이면 충분합니다.初期状態では、サーバーには自宅のネットワーク内からしか接続できません。playit.gg を有効にすれば、どこにいる友だちでも参加できます。ポート開放もルーター設定も固定 IP も不要で、無料の playit.gg アカウントで十分です。

  1. mcctl playit setup

    Paste the agent SECRET_KEY from your playit.gg account.playit.gg 계정에서 발급한 에이전트 SECRET_KEY를 입력합니다.playit.gg アカウントで発行したエージェントの SECRET_KEY を入力します。

  2. mcctl playit start

    Start the playit-agent container next to mc-router.mc-router 옆에서 playit-agent 컨테이너를 실행합니다.mc-router の隣で playit-agent コンテナを起動します。

  3. Minecraft Java → localhost:25565

    On playit.gg, add a Minecraft Java tunnel that points to localhost:25565.playit.gg에서 localhost:25565로 향하는 Minecraft Java 터널을 추가합니다.playit.gg で、localhost:25565 に向けた Minecraft Java トンネルを追加します。

  4. mcctl create myserver -t PAPER -v 1.21.1 --playit-domain xx-xx.craft.playit.gg

    Register the tunnel domain. Friends join xx-xx.craft.playit.gg — no port number.터널 도메인을 서버에 등록합니다. 친구는 포트 번호 없이 xx-xx.craft.playit.gg로 접속합니다.トンネルのドメインをサーバーに登録します。友だちはポート番号なしで xx-xx.craft.playit.gg に接続します。

The tunnel lands on mc-router, so a sleeping server still wakes when a friend joins. You can also start or stop the agent from the web console's Routing page. playit.gg is a separate third-party service.터널은 mc-router로 들어오므로 친구가 접속해도 잠든 서버가 똑같이 깨어납니다. 에이전트는 웹 콘솔의 라우팅 화면에서도 켜고 끌 수 있습니다. playit.gg는 별도의 외부 서비스입니다.トンネルは mc-router に届くので、友だちが接続すれば眠っているサーバーも同じように起動します。エージェントは Web コンソールのルーティング画面からも起動・停止できます。playit.gg は別のサードパーティサービスです。

07 / About소개紹介

Built by a dad, for two brothers.두 형제를 위해, 아빠가 만들었습니다.父が、ふたりの兄弟のために作りました。

I'm a software engineer and the dad of two boys. When they were little they loved Minecraft — and more than anything, they loved playing it together.저는 아들 둘을 둔 소프트웨어 개발자입니다. 형제는 어릴 때부터 마인크래프트를 좋아했고, 무엇보다 같이 하는 걸 좋아했습니다.私は息子ふたりを持つソフトウェアエンジニアです。兄弟は小さい頃から Minecraft が大好きで、何より一緒に遊ぶのが好きでした。

Then came 2020. COVID closed the schools and the playgrounds, and Minecraft became the one place my younger son could still meet his friends.

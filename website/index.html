Docker Minecraft server managerDocker 마인크래프트 서버 매니저

Run them in Docker. Wake them when players connect. Docker로 띄우고, 플레이어가 오면 깨웁니다.

mcctl puts every Minecraft Java server you host behind a single port. A server starts when the first player connects and stops after it goes idle, so an empty host runs only the router — about 40 MB of RAM. Manage it all from the CLI or the web console. mcctl은 직접 운영하는 마인크래프트 자바 서버를 포트 하나 뒤에 모읍니다. 첫 플레이어가 접속하면 서버가 켜지고, 아무도 없으면 다시 꺼집니다. 그래서 빈 호스트에는 라우터만 남습니다(RAM 약 40MB). 관리는 CLI나 웹 콘솔에서 합니다.

$ npm install -g @minecraft-docker/mcctl

01 / Features기능

Built for people who host for friends.친구들 서버를 직접 굴리는 사람을 위해.

01

One port, every server포트 하나로 모든 서버

mc-router reads the hostname a player connects with and forwards them to the matching container. Use nip.io names with no client setup, .local names over mDNS, or a playit.gg tunnel for friends outside your network.mc-router가 접속 주소의 호스트명을 보고 해당 컨테이너로 연결합니다. 클라이언트 설정이 필요 없는 nip.io 주소, mDNS(.local) 주소, 외부 친구용 playit.gg 터널을 지원합니다.

survival.192.168.1.50.nip.io→mc-survival
creative.local→mc-creative
xx-xx.craft.playit.gg→mc-modded
02

Asleep until someone joins누군가 들어올 때까지 잠들기

Servers start on the first connection and stop after an idle timeout. When nobody is playing, only the router and its helpers stay up.첫 접속에 서버가 켜지고, 일정 시간 아무도 없으면 꺼집니다. 아무도 플레이하지 않을 때는 라우터와 보조 서비스만 남습니다.

survivalrunning
moddedstarting
creativeexited
03

Mods and modpacks from the CLI모드와 모드팩을 CLI로

Search and add mods from Modrinth, CurseForge, and Spiget. Create a server straight from a Modrinth modpack — the loader is detected and client-only mods are left out.Modrinth, CurseForge, Spiget에서 모드를 찾아 추가합니다. Modrinth 모드팩으로 바로 서버를 만들면 로더를 자동으로 감지하고 클라이언트 전용 모드는 뺍니다.

$ mcctl create pack -t MODRINTH --modpack cobblemon
04

Worlds that move between servers서버를 옮겨 다니는 월드

Worlds live in one shared directory. Assign a world to a server and it stays locked until released. Import worlds from ZIP, then browse dimensions, structures, players, and a BlueMap web map.월드는 공용 디렉터리 한곳에 보관됩니다. 서버에 할당한 월드는 해제할 때까지 잠깁니다. ZIP으로 월드를 가져오고 차원·구조물·플레이어 정보와 BlueMap 웹 지도를 볼 수 있습니다.

$ mcctl world assign hardcore-01 survival
05

Backups to your GitHub내 GitHub로 백업

Push world data to a private GitHub repository on demand or on a cron schedule with retention, and restore from any backup commit.월드 데이터를 비공개 GitHub 저장소에 직접 또는 cron 일정으로 푸시하고 보관 정책을 적용합니다. 원하는 백업 커밋으로 복원할 수 있습니다.

$ mcctl backup schedule add --cron daily
06

A web console when you want one필요할 땐 웹 콘솔

mcctl console init adds a Next.js console and a REST API: file manager, server.properties editor, player panels, audit logs, and an installable PWA.mcctl console init으로 Next.js 콘솔과 REST API를 추가합니다. 파일 관리자, server.properties 편집기, 플레이어 패널, 감사 로그, 설치형 PWA를 제공합니다.

:5000 web console :5001 REST API PM2

03 / Architecture아키텍처

One port in. One container per server.들어오는 포트는 하나, 서버마다 컨테이너 하나.

Built on itzg/minecraft-server and itzg/mc-router. No firewall rule per server, no port list to remember.itzg/minecraft-server와 itzg/mc-router 기반. 서버마다 방화벽 규칙을 열거나 포트 번호를 외울 필요가 없습니다.

Get started시작하기

Your first server in four commands.명령 네 줄이면 첫 서버가 뜹니다.

Needs Node.js 18+ and Docker Engine 24+ on Linux or macOS. Your existing Minecraft client is all players need.Linux 또는 macOS에 Node.js 18+, Docker Engine 24+가 필요합니다. 플레이어는 평소 쓰던 마인크래프트 클라이언트만 있으면 됩니다.

$ npm install -g @minecraft-docker/mcctl
$ mcctl init
$ mcctl create myserver -t PAPER -v 1.21.1
$ mcctl console init   # optional: web console
Quickstart 빠른 시작 GitHub

Then connect to myserver.<HOST_IP>.nip.io:25565 그다음 myserver.<HOST_IP>.nip.io:25565로 접속하세요

    설정 개요¶

    이 섹션에서는 Docker Minecraft Server 플랫폼의 모든 설정 옵션을 다룹니다.

    mcctl로 빠른 설정¶

    mcctl은 서버를 설정하는 가장 쉬운 방법을 제공합니다:

    # 모든 설정 보기
mcctl config myserver

# 특정 설정 보기
mcctl config myserver MOTD

# 설정 변경
mcctl config myserver MOTD "내 서버에 오신 것을 환영합니다!"
mcctl config myserver MAX_PLAYERS 50
mcctl config myserver MEMORY 8G

# 단축 옵션 사용
mcctl config myserver --cheats        # 치트 활성화
mcctl config myserver --no-pvp        # PvP 비활성화
mcctl config myserver --command-block # 커맨드 블록 활성화

    권장 접근 방식

    대부분의 설정 변경에는 mcctl config를 사용하세요. 유효성 검사를 처리하고 변경 사항을 올바르게 적용합니다.

    설정 파일¶

    참고로 플랫폼은 다음 설정 파일들을 사용합니다(~/minecraft-servers/ 아래):

    파일 용도 관리 주체
    .env 플랫폼 설정. servers/global.env에 이름이 있는 키만 서버에 전달됩니다 mcctl init
    servers/global.env 모든 서버에 전달할 .env 키의 이름 mcctl init, mcctl upgrade
    servers/<name>/server.yaml 서버 정의 mcctl create, mcctl config 및 그 밖의 모든 mcctl 변경
    servers/<name>/config.env 서버 환경 변수, server.yaml에서 생성 mcctl
    docker-compose.yml 메인 오케스트레이션: mc-router와 그 설정 mcctl init
    servers/<name>/docker-compose.yml 서버 컨테이너, server.yaml에서 생성 mcctl
    servers/compose.yml 서버 compose 파일 목록 mcctl

    mcctl이 생성 파일을 어떻게 맞춰 두는지는 서버 정의 (server.yaml)를 참고하세요.

    일반적인 설정 작업¶

    서버 메모리 변경¶

    mcctl config myserver MEMORY 8G
mcctl stop myserver && mcctl start myserver

    Minecraft 버전 변경¶

    mcctl config myserver VERSION 1.21.1
mcctl stop myserver && mcctl start myserver

    VERSION을 바꿔도 서버의 Java 이미지는 바뀌지 않습니다. 새 서버는 VERSION에 필요한 태그를 받습니다. VERSION을 바꾼 뒤에는 mcctl update를 실행하거나 Java 버전과 이미지 태그를 참고하세요.

    모드/플러그인 활성화¶

    모드 서버(Forge/Fabric)의 경우:

    # Modrinth 모드
mcctl config myserver MODRINTH_PROJECTS "fabric-api,lithium,sodium"

# CurseForge 모드 (Java 17+ 이미지에서는 CF_API_KEY 선택 사항)
mcctl config myserver CURSEFORGE_FILES "jei,journeymap"

    플러그인 서버(Paper/Spigot)의 경우 플러그인을 shared/plugins/ 디렉토리에 넣습니다.

    자동 스케일링 설정¶

    mc-router는 자동 스케일링 설정을 .env가 아니라 ~/minecraft-servers/docker-compose.yml의 router 서비스에서 읽습니다:

    services:
  router:
    environment:
      AUTO_SCALE_UP: "true"         # 플레이어 접속 시 서버 자동 시작
      AUTO_SCALE_DOWN: "true"       # 유휴 서버 자동 중지
      AUTO_SCALE_DOWN_AFTER: "10m"  # 유휴 타임아웃
      DOCKER_TIMEOUT: "120s"        # 서버 시작 타임아웃 (Go time.Duration: 120s, 2m)

    # mc-router 상태와 라우트 보기
mcctl status router

# docker-compose.yml 편집 후 mc-router 재생성
mcctl router start

    mcctl router restart는 이전 설정을 그대로 사용합니다. mcctl router start는 편집한 파일로 컨테이너를 다시 만듭니다. mcctl upgrade는 이 파일에서 router의 image와 group_add만 바꾸므로 편집한 내용은 유지됩니다. 한 서버만 자동 스케일링을 끄려면 그 서버의 server.yaml에서 routing.autoScale을 설정합니다.

    서버 속성 변경¶

    # 게임 설정
mcctl config myserver DIFFICULTY hard
mcctl config myserver MODE survival
mcctl config myserver MAX_PLAYERS 30

# 월드 설정
mcctl config myserver SPAWN_PROTECTION 0
mcctl config myserver VIEW_DISTANCE 12

# 화이트리스트 활성화
mcctl whitelist myserver on
mcctl whitelist myserver add Steve

    설정 우선순위¶

    설정은 다음 순서로 적용됩니다 (나중 것이 이전 것을 덮어씀):

    1. 기본값 - itzg/minecraft-server 이미지에 내장
    2. servers/global.env - 이 파일에 이름이 있는 플랫폼 키(TZ, EXTRA_ARGS, RCON_PASSWORD, RCON_PORT), 값은 .env에서 가져옴
    3. 서버 config.env - 서버별 값, server.yaml에서 생성 (mcctl config로 관리)
    4. 서버 docker-compose.yml의 environment - EULA=TRUE만 있음

    그 밖의 .env 키는 서버에 전달되지 않습니다. 모든 서버에 전달하려면 servers/global.env에 이름을 추가하세요(설정 분류 참고).

    유효성 검사¶

    설정 변경 후 서버 상태를 확인합니다:

    # 서버 설정 확인
mcctl config myserver

# 서버 상태 확인
mcctl status myserver

# 오류 확인을 위해 로그 보기
mcctl logs myserver -n 50

    고급 설정¶

    mcctl config에서 지원하지 않는 설정은 파일을 직접 편집합니다:

    # 전역 설정 편집
nano ~/minecraft-servers/.env

# 서버별 설정 편집
nano ~/minecraft-servers/servers/myserver/config.env

# 변경 사항 적용을 위해 재시작
mcctl stop myserver && mcctl start myserver

    mcctl은 config.env와 서버의 docker-compose.yml을 servers/<name>/server.yaml에서 만들어 씁니다. config.env를 손으로 고치면 다음에 mcctl이 그 서버를 바꿀 때 server.yaml로 가져옵니다. docker-compose.yml에서 image와 mc-router.* 라벨 외의 부분(예: 리소스 제한)을 고친 내용은 유지되지만, 나중에 이 파일을 다시 써야 하는 변경은 compose_edited로 멈춥니다. 손으로 고친 경우와 config.env의 값 규칙을 참고하세요.

    직접 파일 편집이 필요한 경우

    직접 파일 편집은 다음 경우에만 필요합니다:

    • 고급 JVM 옵션 (JVM_OPTS, JVM_DD_OPTS)
    • 사용자 지정 환경 변수
    • Docker 리소스 제한

    표준 설정은 mcctl config를 사용하세요.

# 감사 로그 API 참조

감사 로그 라우트는 이제 REST API 레퍼런스에서 설명합니다: [감사 로그](../api/endpoints.ko.md#audit-logs).

| 이전 섹션 | 새 위치 |
|-----------|---------|
| 인증 | [인증](../api/index.ko.md#authentication) |
| GET /audit-logs | [GET /api/audit-logs](../api/endpoints.ko.md#get-apiaudit-logs) |
| GET /audit-logs/stats | [GET /api/audit-logs/stats](../api/endpoints.ko.md#get-apiaudit-logsstats) |
| GET /audit-logs/:id | [GET /api/audit-logs/:id](../api/endpoints.ko.md#get-apiaudit-logsid) |
| DELETE /audit-logs/purge | [DELETE /api/audit-logs](../api/endpoints.ko.md#delete-apiaudit-logs) (JSON 본문, `X-Role: admin` 필요) |
| GET /audit-logs/stream | [GET /api/audit-logs/stream](../api/endpoints.ko.md#get-apiaudit-logsstream) |
| 데이터 타입 | [감사 로그 항목](../api/endpoints.ko.md#audit-log-entries) |
| 오류 응답 | [오류](../api/index.ko.md#errors) |

[CLI - 감사 로그 명령어](../cli/audit-log.ko.md)와 [웹 콘솔 - 감사 로그 UI](./audit-log-ui.ko.md)도 참고하세요.
